# Pump Token Creator - Installation Guide

## Prerequisites

1. **Chrome Browser** (or any Chromium-based browser)
2. **Solana Wallet Extension** (Phantom, Solflare, etc.)
3. **Access to X/Twitter** account

## Step 1: Install the Extension

### Option A: Load Unpacked (Development)
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" toggle in the top-right corner
3. Click "Load unpacked" button
4. Navigate to and select the `browser-extension` folder
5. The extension should appear in your extensions list

### Option B: Chrome Web Store (Coming Soon)
1. Visit the Chrome Web Store
2. Search for "Pump Token Creator"
3. Click "Add to Chrome"
4. Confirm installation

## Step 2: Pin the Extension

1. Click the puzzle piece icon (🧩) in your browser toolbar
2. Find "Pump Token Creator" in the list
3. Click the pin icon (📌) to pin it to your toolbar
4. The 🚀 icon should now be visible in your toolbar

## Step 3: Install a Solana Wallet

If you don't have a Solana wallet installed:

### Phantom Wallet (Recommended)
1. Visit [phantom.app](https://phantom.app)
2. Click "Download" and select "Chrome"
3. Install the extension from Chrome Web Store
4. Follow setup instructions to create a new wallet
5. **Important**: Save your seed phrase securely!

### Alternative Wallets
- **Solflare**: Visit [solflare.com](https://solflare.com)
- **Backpack**: Visit [backpack.app](https://backpack.app)

## Step 4: First Time Setup

1. Click the Pump Token Creator icon (🚀) in your toolbar
2. Click "Connect Wallet" 
3. Select your preferred wallet from the list
4. Approve the connection request in your wallet
5. Your wallet address should now appear in the extension

## Step 5: Test the Extension

### Test Wallet Connection
1. Ensure your wallet is connected (green indicator)
2. Your wallet address should be displayed (truncated)

### Test on Twitter/X
1. Navigate to [x.com](https://x.com) or [twitter.com](https://twitter.com)
2. Look for tweets with the 🚀 button
3. Click the extension icon to see the "Posts" and "Create Token" tabs

## Troubleshooting

### Extension Not Loading
- Ensure Developer Mode is enabled in Chrome
- Try refreshing the extensions page
- Check browser console for error messages

### Wallet Not Connecting
- Ensure your wallet extension is installed and unlocked
- Try refreshing the Twitter/X page
- Disable other wallet extensions temporarily

### 🚀 Buttons Not Appearing
- Refresh the Twitter/X page
- Check if the extension is enabled
- Look in the browser console for error messages

### Extension Icon Missing
- Check if the extension is enabled in `chrome://extensions/`
- Try unpinning and re-pinning the extension
- Restart Chrome browser
