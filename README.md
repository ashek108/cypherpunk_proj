# PumpX

Turn viral tweets into tokens in one click. PumpX adds a button to every X post, letting you instantly launch a pump.fun coin from the hottest memes and moments.

## Features

### 🔐 Wallet Integration
- Connect your Solana wallet (Phantom, Solflare, Backpack, Coin98)
- No keys stored; signing happens in your wallet

### 🚀 1‑Click Token Launch
- Create tokens directly from tweets on X
- Auto‑suggested name and symbol from tweet content
- Uses pump.fun’s transaction APIs under the hood

### 📈 Viral Feed
- Browse recent tokens created with PumpX
- Sort by newest, popularity, or market cap
- Opens pump.fun token page in one click

### 🎯 Smart Tweet Detection
- Adds a small PumpX button near tweet actions on X
- Skips promoted/advertising tweets
- Shows a lightweight preview before creation

## Installation
1. Clone this repository
2. Open Chrome (or Edge) and navigate to `chrome://extensions/`
3. Enable Developer mode (top‑right)
4. Click "Load unpacked" and select this `browser-extension` folder
5. You should see PumpX in your extensions list


## How it works
- Connect Your Wallet
- Create From a Tweet
- Viral Feed

Note: `solanaWeb3.iife.min.js` is intentionally included and required at runtime.
